# Hermeneus 传译者

> 🚀 本地 AI 实时同声传译（macOS）

Hermeneus 基于本地 AI
模型运行，无需云端接口，可实现低延迟实时语音识别、翻译与字幕显示。

------------------------------------------------------------------------

## ✨ 功能特点

-   🎙️ 实时语音识别（ASR）
-   🌍 本地 AI 翻译（Ollama）
-   💬 悬浮字幕实时显示
-   🔒 全程本地运行
-   ⚡ 一条命令启动

------------------------------------------------------------------------

# 🚀 快速开始

首次安装仅需执行一次。

  步骤   说明
  ------ -------------------------
  1      安装 Homebrew 与 Ollama
  2      下载 Qwen 模型
  3      安装 Hermeneus
  4      配置启动脚本
  5      开始使用

------------------------------------------------------------------------

# ① 安装 Homebrew 与 Ollama

``` bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install ollama
```

------------------------------------------------------------------------

# ② 下载翻译模型

启动 Ollama：

``` bash
nohup ollama serve >/dev/null 2>&1 &
sleep 2
```

下载模型：

``` bash
ollama pull qwen2.5:3b
```

> **注意**
>
> Hermeneus 设置中的模型名称必须与 `ollama list` 显示一致（例如
> `qwen2.5:3b`）。

------------------------------------------------------------------------

# ③ 安装 Hermeneus

下载最新版：

    Hermeneus-macOS-vX.X.X-Full.dmg

将 **Hermeneus.app** 拖入 **Applications（应用程序）**。

# ▶️ 启动

以后无需重复安装。

打开终端：

``` bash
hermeneus
```

程序将自动：

-   ✅ 启动 Ollama
-   ✅ 加载本地模型
-   ✅ 清理 Gatekeeper 隔离
-   ✅ 启动 ASR 服务
-   ✅ 打开 Hermeneus

# 🎤 使用说明

### 对方讲话

系统自动：

1.  识别语音
2.  翻译内容
3.  实时字幕显示

### 自己讲话

按住 **Option（⌥）** 键说话。

松开按键后将自动：

1.  语音识别
2.  翻译
3.  播放给对方

# ❓ 常见问题

**模型无法下载？**

确认：

-   Ollama 已启动
-   网络连接正常
-   模型名称填写正确

**启动失败？**

重新执行：

``` bash
hermeneus
```

若仍失败，请检查启动脚本或重新安装 Ollama。
